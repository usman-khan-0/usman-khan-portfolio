                    1. PROJECT OVERVIEW & DESCRIPTION
================================================================================

TITLE: Small-Scale Ballistic Missile Development System

DESCRIPTION:
An academic-grade engineering research project covering structural design, solid 
propellant propulsion, flight dynamics, guidance systems, and trajectory 
simulation for a small-scale ballistic missile prototype.

PROJECT SCOPE:
This comprehensive academic research project simulates real-world ballistic 
missile development at a reduced academic scale — covering every engineering 
discipline from propellant chemistry to guidance algorithms.

TARGET SPECIFICATIONS (Small-Scale Academic Prototype):
- Target Range: 100–500 meters
- Maximum Altitude: 150–500 meters
- Launch Mass: 0.5–3 kg
- Payload: Data logger or dummy mass

                    5. FLIGHT PHASES
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│  BOOST PHASE                                                                │
│  ─────────────                                                              │
│  • Description:    Powered flight from ignition to fuel exhaustion          │
│  • Propulsion:     Multi-stage rocket with internal computers               │
│  • Events:         Stage separation occurs                                  │
│  • Duration:       Tenths of seconds to several minutes                     │
│  • Characteristics: Maximum acceleration and dynamic pressure (max-Q)       │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  MID-COURSE PHASE                                                           │
│  ──────────────────                                                         │
│  • Description:    Longest trajectory phase, missile in free flight         │
│  • Thrust:         None (ballistic coast)                                   │
│  • Altitude:       May travel through space at extreme altitudes            │
│  • Apogee:         ~4,500 km for ICBMs                                      │
│  • Velocity:       7.5–10 km/s (4–5 nautical miles/s)                       │
│  • Characteristics: Warhead/payload with possible countermeasures,          │
│                     MIRV and decoy deployment                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  TERMINAL/RE-ENTRY PHASE                                                    │
│  ─────────────────────                                                      │
│  • Description:    Begins at atmospheric re-entry                           │
│  • Forces:         Aerodynamic forces become significant                    │
│  • Heating:        Extreme aerodynamic heating (up to 2,000°C)              │
│  • Re-entry Velocity: 6–8 km/s (22,000–29,000 km/h)                        │
│  • Characteristics: Atmospheric drag significantly affects trajectory,      │
│                     final impact point determination                        │
└─────────────────────────────────────────────────────────────────────────────┘

                    6. KEY TECHNICAL SPECIFICATIONS
================================================================================

THROW-WEIGHT:
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Definition:       Measure of effective payload weight (kg or tonnes)     │
│  • Includes:         Warheads, re-entry vehicles, dispensing mechanisms,    │
│                      penetration aids                                       │
│  • Excludes:         Booster rockets and fuel                               │
│  • Application:      Classification criterion in arms control treaties      │
│                      (SALT)                                                 │
│  • Heaviest:         Russian SS-18, Chinese CSS-4                           │
└─────────────────────────────────────────────────────────────────────────────┘

MIRV TECHNOLOGY:
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Full Form:        Multiple Independently Targetable Re-entry Vehicles    │
│  • Capability:       Single missile carries multiple warheads for different │
│                      targets                                                │
│  • Deployment:       Post-boost vehicle (PBV) or "bus" maneuvers to         │
│                      release RVs + decoys + chaff                           │
│  • First MIRV ICBM:  Minuteman III (1970)                                   │
└─────────────────────────────────────────────────────────────────────────────┘

TRAJECTORY VARIANTS:
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Standard:         Traditional ballistic arc                              │
│  • Depressed:        Flatter trajectory to evade ABM systems                │
│  • Lofted:           Higher apogee, reduced range (used for testing)        │
│  • Minimum-Energy:   Maximizes throw-weight                                 │
└─────────────────────────────────────────────────────────────────────────────┘

HYPERSONIC FLIGHT:
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Speed:            Mach 5+ during re-entry                                │
│  • HGV:              Hypersonic glide vehicles perform atmospheric          │
│                      maneuvers                                              │
│  • Distinction:      Real-time aerodynamic calculations vs. traditional     │
│                      ballistic trajectory                                   │
│  • Examples:         Kinzhal, Oreshnik, Avangard                            │
└─────────────────────────────────────────────────────────────────────────────┘

7.1 AIRFRAME / BODY TUBE DESIGN
─────────────────────────────────

GEOMETRY & SIZING:
┌─────────────────────────────────────────────────────────────────────────────┐
│  Parameter        │ Specification                                          │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Diameter         │ 75–150 mm (based on motor size)                        │
│  Length           │ Determined by fineness ratio (L/D = 10–15)             │
│  Wall Thickness   │ 2–4 mm (composite), 1.5–3 mm (aluminum)                │
│  Material         │ CFRP, fiberglass G12, aluminum 6061-T6                 │
│  Surface Finish   │ Smooth exterior (minimize skin friction drag)          │
└─────────────────────────────────────────────────────────────────────────────┘

STRUCTURAL CONSIDERATIONS:
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Max-Q Resistance:     Withstand maximum dynamic pressure without         │
│                          buckling                                           │
│  • Motor Thrust Load:    Bulkheads transfer thrust to airframe              │
│  • Landing Impact:       Reinforced sections at recovery attachment points  │
│  • Thermal Protection:   Internal insulation near motor section             │
└─────────────────────────────────────────────────────────────────────────────┘

DESIGN FORMULAS:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  Fineness Ratio = Length / Diameter (Optimal: 10–15)                       │
│                                                                             │
│  Critical Buckling Pressure:                                                │
│  P_cr = (2 × E × t³) / (D³ × (1 - ν²))                                     │
│                                                                             │
│  Where:                                                                     │
│    E  = Young's modulus                                                     │
│    t  = Wall thickness                                                      │
│    D  = Diameter                                                            │

7.6 STEP-BY-STEP ASSEMBLY PROCEDURE
───────────────────────────────────

PHASE 1: AIRFRAME PREPARATION (Steps 1-6)
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. Cut body tube to final length (fine-tooth saw or tube cutter)          │
│  2. Sand cut edges smooth, deburr interior and exterior                    │
│  3. Mark fin slot locations (alignment jig: 120° for 3-fin, 90° for 4-fin) │
│  4. Cut fin slots (router/Dremel with guide, depth = 1.5× fin root)        │
│  5. Drill vent holes (4× 6 mm near forward and aft ends)                   │
│  6. Clean interior with isopropyl alcohol for bonding prep                 │
└─────────────────────────────────────────────────────────────────────────────┘

PHASE 2: MOTOR MOUNT ASSEMBLY (Steps 7-13)
┌─────────────────────────────────────────────────────────────────────────────┐
│  7.  Cut motor tube to length (motor + 25 mm)                              │
│  8.  Cut centering rings from plywood/G10                                  │
│  9.  Test fit motor tube through centering rings (slight friction)         │
│  10. Apply epoxy to motor tube, slide on centering rings, wipe excess      │
│  11. Allow epoxy to cure 24 hours at room temperature                      │
│  12. Install motor retainer (screw threads or engine hook) at aft end      │
│  13. Slide motor mount into airframe, bond aft centering ring              │
└─────────────────────────────────────────────────────────────────────────────┘

PHASE 3: FIN INSTALLATION (Steps 14-21)
┌─────────────────────────────────────────────────────────────────────────────┐
│  14. Cut fins from material using template (identical geometry)            │
│  15. Sand fins to airfoil shape (rounded LE, sharp TE)                    │
│  16. Dry-fit fins into slots (snug fit without gaps)                       │
│  17. Apply epoxy to fin root and slot walls                                │
│  18. Insert fins, ensure perpendicular alignment (use square tool)         │
│  19. Apply fillet bead along fin-airframe joint (epoxy + microballoons)    │
│  20. Allow 24 hours cure time, sand fillets smooth                         │
│  21. Prime and paint fins if desired (multiple light coats)                │
└─────────────────────────────────────────────────────────────────────────────┘

PHASE 4: BULKHEADS & RECOVERY (Steps 22-29)
┌─────────────────────────────────────────────────────────────────────────────┐
│  22. Cut bulkheads from plywood/aluminum (diameter = airframe ID - 0.5 mm) │
│  23. Drill wire pass-through holes, install grommets                       │
│  24. Bond aft bulkhead above motor mount (epoxy + screws)                  │
│  25. Install shock cord anchor point on forward bulkhead                   │
│  26. Assemble parachute, shock cord, and deployment bag                    │
│  27. Load black powder ejection charge in deployment well                  │
│  28. Thread avionics wiring through bulkhead pass-throughs                 │
│  29. Verify all connections and clearances                                 │
└─────────────────────────────────────────────────────────────────────────────┘

PHASE 5: NOSE CONE & FINAL ASSEMBLY (Steps 30-37)
┌─────────────────────────────────────────────────────────────────────────────┐
│  30. Machine or 3D print nose cone to specification                        │
│  31. Sand nose cone shoulder for smooth fit (no binding, no wobble)        │
│  32. Install retention screw or bayonet mount                              │
│  33. Attach shock cord to nose cone base                                   │
│  34. Install avionics bay (flight computer, battery, sensors)              │
│  35. Pack recovery system (deployment bag → parachute → shock cord)        │
│  36. Final balance check: locate CG with motor installed                   │
│  37. Apply final paint/decal scheme (lightweight paint only)               │
└─────────────────────────────────────────────────────────────────────────────┘

8.3 PID FLIGHT CONTROL SYSTEM
────────────────────────────

PID CONTROLLER FUNDAMENTALS:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  output = Kp × error + Ki × ∫error × dt + Kd × d(error)/dt                 │
│                                                                             │
│  Where:                                                                     │
│    Kp (Proportional):  Response to current error                           │
│    Ki (Integral):      Eliminates steady-state error                       │
│    Kd (Derivative):    Dampens oscillations, predicts future               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

THREE-AXIS CONTROL:
┌─────────────────────────────────────────────────────────────────────────────┐
│  Axis      │ Description                                                    │
│  ─────────────────────────────────────────────────────────────────────────  │
│  Pitch     │ Nose up/down rotation                                          │
│  Yaw       │ Nose left/right rotation                                       │
│  Roll      │ Clockwise/counterclockwise rotation                            │
│                                                                             │
│  Control Loop Rate: 500–1000 Hz for stable flight                          │
└─────────────────────────────────────────────────────────────────────────────┘

FIN ACTUATION (SERVO MOTORS):
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Servo Type:       Digital high-speed (0.06–0.08 sec/60°)                │
│  • Torque:           ≥ 5 kg·cm (small fins), ≥ 10 kg·cm (larger)           │
│  • Examples:         BMS-2275, MKS DS95i, Hitec D85MG                      │
│  • Control Signal:   PWM (50 Hz, 1000–2000 μs pulse width)                 │
│  • Power:            5–6 V BEC (Battery Eliminator Circuit)                │
│  • Mounting:         Direct horn attachment or pushrod linkage             │
└─────────────────────────────────────────────────────────────────────────────┘

THRUST VECTOR CONTROL (TVC):
┌─────────────────────────────────────────────────────────────────────────────┐
│  • Method:           Gimbaled nozzle with 2–4 actuators                    │
│  • Actuators:        High-torque servos or linear actuators                │
│  • Deflection:       ±3–5° vectoring angle                                 │
│  • Response:         Must be faster than aerodynamic control               │
│  • Advantage:        Control at low speeds (before fins are effective)     │
│  • Complexity:       Higher than fin control, requires robust mechanism    │
└─────────────────────────────────────────────────────────────────────────────┘

PID TUNING PROCEDURE:
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 1: Initialize                                                         │
│          Set Ki = 0, Kd = 0. Start with low Kp (0.1–0.5).                  │
│                                                                             │
│  Step 2: Tune Kp                                                            │
│          Increase Kp until system oscillates, then reduce by 30%.          │
│                                                                             │
│  Step 3: Tune Kd                                                            │
│          Add derivative gain to dampen oscillations.                       │
│          Watch for noise amplification.                                    │
│                                                                             │
│  Step 4: Tune Ki                                                            │
│          Add integral gain to eliminate steady-state error.                │
│          Use sparingly.                                                    │
│                                                                             │
│  Step 5: Flight Test                                                        │
│          Fine-tune gains based on actual flight performance.               │
│          Log data for analysis.                                            │
│                                                                             │
│  Typical Values:                                                            │
│    Kp: 0.5–2.0                                                              │
│    Ki: 0.001–0.01                                                           │
│    Kd: 0.05–0.2 (axis-dependent)                                            │
└─────────────────────────────────────────────────────────────────────────────┘

8.4 GUIDANCE & NAVIGATION ALGORITHMS
────────────────────────────────────

EXTENDED KALMAN FILTER (EKF):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PREDICT STEP:                                                              │
│  ───────────────                                                            │
│  x̂ₖ⁻ = F × x̂ₖ₋₁ + B × uₖ                                                   │
│  Pₖ⁻ = F × Pₖ₋₁ × Fᵀ + Q                                                    │
│                                                                             │
│  UPDATE STEP:                                                               │
│  ─────────────                                                              │
│  Kₖ = Pₖ⁻ × Hᵀ × (H × Pₖ⁻ × Hᵀ + R)⁻¹                                      │
│  x̂ₖ = x̂ₖ⁻ + Kₖ × (zₖ - H × x̂ₖ⁻)                                           │
│                                                                             │
│  Where:                                                                     │
│    x̂ = State estimate                                                      │
│    P = Error covariance                                                    │
│    K = Kalman gain                                                         │
│    F = State transition matrix                                             │
│    H = Observation matrix                                                  │
│    Q = Process noise covariance                                            │
│    R = Measurement noise covariance                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

FLIGHT STATE MACHINE:
┌─────────────────────────────────────────────────────────────────────────────┐
│  State           │ Description                                              │
│  ─────────────────────────────────────────────────────────────────────────  │
│  1. IDLE         │ Pre-launch, system checks                                │
│  2. LAUNCH DETECT│ Acceleration threshold trigger                           │
│  3. BOOST        │ Powered ascent, active control                           │
│  4. COAST        │ Ballistic ascent to apogee                               │
│  5. APOGEE       │ Drogue parachute deployment                              │
│  6. DESCENT      │ Main parachute deployment                                │
│  7. LANDING      │ Touchdown detected, data save                            │
└─────────────────────────────────────────────────────────────────────────────┘
